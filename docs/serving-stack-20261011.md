# Serving kernel consolidation: 2026-10-11

This branch combines current remote main, the 33 existing AMD port commits through `bb0c6c5`, and eight Clariden campaign commits through `447728c`. The merge retains main's vectorized, per-query-head MQA reference. Original local worktrees and uncommitted files are preserved; most of that older uncommitted work was already published in the October 10 consolidation.

The Clariden additions cover fused forget-gate projection, explicit mHC norm and KDA BF16-rounding policies, stacked small projections, optional DeepGEMM prefill, bounded inverse-count dispatch, static device-resident expert prefill, fused EP route remapping, and optional FP32 route weighting before the down-output BF16 store. They retain existing defaults for opt-in policies. The bounded dispatch implementation preserves its public input/output contract.

AMD additions include TokenSpeed-derived routing, sorting, sampling, preprocessing and CDNA3 attention implementations, their references, benchmark scripts and original component results. Their existing component measurements are retained under `meta/benchmarks/artifacts/tokenspeed-amd-bucket1/`; they are not a new full-model Beverin qualification. GPU tests now require ROCm before compiling CDNA instructions. MLA decode exposes only the existing BF16 `bh16bn64` port; unreachable FP8 and other-regime fragments with undefined names are removed. The supported BF16 path's arithmetic is unchanged.

Fresh combined-tree validation uses local GB10, Torch 2.13/cu130 and Triton 3.7.1. The final focused kernel suite passes 185 cases with 32 skips: three require SM90 DeepGEMM, 24 require ROCm, four launcher-contract cases require Triton 3.8 Gluon aggregates, and one documents unsupported duplicate-slot races. Production Ruff passes. See `serving-stack-20261011-validation.json` for exact checks and limits. Existing Clariden campaign target checks remain historical evidence for their individually executed recipes, rather than benchmarks of this combined tree.

Floe's coordinated branch records original source-to-consolidation commit mappings and compact campaign evidence at `notes/performance/2026-10-11-serving-stack/`. Matched serial held-out quality fails the user's +0.01 tolerance for both EP1 (+0.02675 nats/token) and weighted EP4 (+0.03274). Gloo control transport gives no reliable decode speedup. These failures preclude promoting the combined experimental recipe. Kvaas authority is unchanged. A new full-model combined-tree benchmark is still required before performance or quality claims.
